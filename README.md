# Loan Amortization Analysis

An object-oriented Python application for calculating and analyzing
loan amortization under different repayment scenarios, with an
interactive Power BI dashboard for visual analysis.

## Project Overview

This project calculates loan repayment schedules and analyzes how
different repayment conditions affect:

- Total payment
- Total principal
- Total interest
- Loan duration
- Monthly interest and principal payments

The Python implementation uses Object-Oriented Programming to create
a reusable loan calculation structure that can be applied to multiple
scenarios with minimal additional code.

The resulting data is then visualized using Matplotlib and Power BI.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Object-Oriented Programming
- Power BI
- DAX


## Methodology

1. Define loan parameters
2. Create loan object
3. Calculate amortization schedule
4. Apply different repayment scenarios
5. Generate analytical outputs
6. Visualize results using Matplotlib
7. Import results into Power BI
8. Build an interactive dashboard

## Scenarios

The model includes four repayment scenarios designed to demonstrate
how the same underlying loan can behave under different conditions.
